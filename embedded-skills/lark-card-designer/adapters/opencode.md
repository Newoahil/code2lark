# OpenCode Adapter

This is a thin entry point. Use the core skill in `../SKILL.md` and load references from `../references/` as directed there.

Invoke this skill when a task involves Feishu/Lark card design, JSON 2.0 feasibility, information architecture, component choice, visual/status rules, interaction states, or review of an existing card. Run the mandatory compatibility gate in the core skill, use only verified official component names in implementation-facing mappings, and provide conservative fallbacks for conditional capabilities. Keep the result as design guidance and a non-production component map. Do not duplicate or fork the core rules in this adapter.
